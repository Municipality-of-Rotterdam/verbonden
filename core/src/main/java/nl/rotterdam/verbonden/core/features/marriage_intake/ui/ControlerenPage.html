Je staat op het punt om alles naar de gemeente Rotterdam te sturen en te betalen.

Bij het bevestigen word je naar de betalingspagina geleid.

Je krijgt daarna ook een bevestiging per e-mail.

De reservering blijft 3 dagen geldig. In deze periode kun je alles gratis aanpassen. Na deze 3 dagen is wijzigen niet meer mogelijk.

Let op: Annuleer je na de 3 dagen bedenktijd? Dan rekenen we € 50,- administratiekosten per keer.

Vul eerst alle onderdelen in. Daarna kunnen jullie je keuzes bevestigen.
